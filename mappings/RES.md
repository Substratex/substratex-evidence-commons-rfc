# ECS ↔ Runtime Evidence Standard (RES)

ECS consumes and preserves evidence artifacts; RES defines Runtime Evidence formation and lifecycle semantics.

ECS does not redefine:

- qualified source;
- canonical runtime;
- Current Evidence Run;
- Runtime Evidence Record;
- Certified Runtime Evidence Record;
- bounded finding;
- Runtime Evidence Passport;
- Evidence Seal;
- RES missingness or support-class semantics.

An ECS artifact carrying RES evidence should preserve the RES version, conformance profile, stable evidence identity, lineage, challenge state, integrity references, and disclosure limitations.

ECS comparability may inspect RES method/version/horizon metadata, but comparability does not validate the scientific construct.
