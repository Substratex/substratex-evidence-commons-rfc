# Changelog

## ECS 1.0 RFC Draft — 2026

Initial clean-slate RFC repository.

Introduces:

- federatable Commons architecture;
- durable artifact / non-durable interface principle;
- artifact admission;
- privacy/disclosure postures;
- publication classes;
- explicit comparability contracts;
- challenge, counterevidence, review, supersession, and withdrawal;
- aggregation governance;
- preservation events and immutable history;
- repository-to-repository federation and custody transfer;
- governance and moderation boundaries;
- RES / EGC / ECS separation;
- JSON Schema 2020-12 interchange profile;
- conformance profiles and canonical fixtures.
